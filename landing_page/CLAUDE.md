# keril.art — личный лендинг (визитка)

## Что это
Одностраничный сайт-визитка для keril.art. Фронтенд находится в
`index.html`, CSS инлайновый, без сборщиков и фреймворков. PHP endpoint
`counter.php` считает посещения и пишет журнал; для счётчика на сервере
нужны nginx и PHP-FPM.

В будущем на поддоменах появятся отдельные страницы пет-проектов —
это отдельные одностраничники, никак не завязанные на этот файл.

## Эстетика (держаться этого стиля при любых правках)
Тематика сайта: **Frutiger Aero**, **Tenshi Kawaii** и **Windows XP**.
Глянец и стекло, небо и космос, пастельная «ангельская» милота (звёздочки,
сердечки, пузырьки, розовые акценты) и интерфейс в духе XP Luna (окна с
тайтл-барами, выпуклые кнопки). Не уводить в другие темы (море/пляж,
плоский минимализм, киберпанк-неон и т.п.).

"Cyber Frutiger Aero" — глянцевый Y2K/Windows-XP-era стиль:
- глянцевые выпуклые кнопки в духе Windows XP Luna (градиент светлый→синий,
  белый блик сверху, скошенная "sheen"-анимация — см. класс `.sheenbox`)
- хром-градиентный текст у заголовка (`background-clip:text`)
- фон — фиксированный слой `.scene` на весь экран: sky-blue градиент +
  статичный узор белых точечек (SVG data URI) + два canvas: самый нижний
  `#water-canvas` (волны) и над ним `#scene-canvas` (фигуры); оба под контентом.
  На canvas плавают пузырьки, звёздочки, сердечки и белые точки размером
  5–35px; их число зависит от площади окна (`floaterArea`, максимум 300).
  Ушедшие за край заменяются новыми с края. Курсор отталкивает фигуры и
  меняет их курс; за курсором — симуляция волн на сетке высот
  (`waterCellSize`, `waterDamping`), как след от палочки в воде.
  Если острие курсора проходит через фигуру, она с шансом
  `floaterPopChance` (40%, один бросок на касание) лопается с колечком и
  брызгами (`popFloater`, `drawPopEffects`), на её место приплывает новая.
  3 лопания за 0.3с (`popComboCount`, `popComboWindow`) — с краёв влетают
  ещё 5 фигур (сверх обычного количества не больше `extraFloaterLimit`).
  Комбо-цепочка: каждое лопание продлевает её на `comboTimeout` (3.125с).
  На комбо 50 справа вылетает окно `#bubble-counter` ("пузыри.exe") со
  счётом "N /цель" и полоской оставшегося времени в стиле загрузки XP —
  убывает целыми блоками. Цель — следующая сотня: 100/100, затем 101/200.
  Обрыв комбо до 100 — тряска и откат счёта к 0; после 100 — свечение и
  откат. Кнопки окна работают: "свернуть" поворачивает окно на 90° и
  прижимает его вдоль правого края язычком, в заголовке идёт живой счёт
  ("пузыри: 57"); "закрыть" уносит его вправо, при следующем комбо 50 оно
  прилетит снова. Каждая сотня (`comboMilestone`) — свечение и струя из
  200 фигур за 0.7с (`bubbleStreamCount`, у неё свой запас сверх лимита,
  стартовая скорость ×1.75 — летят на 75% дальше), кулдаун струи 60с
  (`bubbleStreamCooldown`; если сотня набрана в кулдаун, струя ждёт и
  срабатывает на первом лопании после него, в окне видна перезарядка).
  Струя — как мыльные пузыри, из случайной точки края окна под углом до
  ±80° от перпендикуляра к краю. Комбо 1000 (`comboFinale`) — финал
  (2с, `finaleDuration`): окно летит в центр, ~1с дрожит и наливается
  свечением, затем взрывается. Ударная волна лопает все фоновые фигуры,
  пузыри взрыва плотно покрывают весь сайт на отдельном холсте
  `#burst-canvas` поверх контента и за 1.8–4.5с лопаются сами; всё,
  что лопается в финале, разбрасывает мерцающие блёстки. Экран
  пустеет, затем за ~4с фигуры налетают с краёв (`refillPausedUntil`,
  `refillGradualUntil`). Окно пропадает, и 10с после финала
  (`comboRestAfterFinale`) комбо не считается (`registerPop`,
  `updateBubbleStream`, `finishCombo`, `updateCombo`,
  `startCounterFinale`, `explodeCounter`)
  При `prefers-reduced-motion` фигуры рисуются статично, без воды
- счётчик посетителей — маленькое XP-окошко `.counter-window`
  ("посетители.exe") в конце `#home-details`
- в конце основной колонки `footer.signature` — авторская подпись
  "made by Keril³" (тройка — `<sup>`, одного размера с "made by"), белая с
  тёмной тенью, между двумя мерцающими розовыми звёздочками; отступ 32px
  как у остальных блоков. Не удалять и не менять текст
- светлая и тёмная ("космос") темы: `html[data-theme="light"|"dark"]`,
  выбор хранится в `localStorage` (`keril-art-theme`), кнопка `#theme-toggle`
  в верхней панели. Скрипт в `<head>` ставит тему до отрисовки. Пока тема
  не выбрана (первый визит), `html.theme-pending` показывает окно
  `#theme-gate`, а `.page-shell` получает `inert` — сайтом нельзя
  пользоваться до выбора. Тёмная тема — блок правил `html[data-theme="dark"]`
  в CSS; окна перекрашиваются через классы `.xp-window`, `.xp-window__bar`,
  `.xp-window__body`, `.skill-tag`. Градиент фона — переменная `--sky`.
  Новые блоки должны выглядеть нормально в обеих темах
- шрифт: `Monocraft` с поддержкой кириллицы; bitmap-пиксельная подача
  для интерфейса и заголовков
- "окна" (`#about`, `#projects`) оформлены как файловые окна с
  псевдо-кнопками свернуть/развернуть/закрыть в правом верхнем углу
  тайтл-бара
- никаких готовых UI-библиотек, никакого Bootstrap/Tailwind — только
  руками написанный CSS, чтобы сохранять именно этот неповторимый вид

## Цветовая палитра
```
sky1       #EAF6FF   верх фонового градиента
sky2       #7FCDFB   середина
sky3       #2E7FE0   низ
accent     #4FA8E8   основной голубой акцент (бордеры, иконки)
accentDark #1C5FC4   тёмный акцент (хедеры окон, обводки)
glow       #CFEBFF   светлый акцент (градиенты, подсветка)
deep/ink   #0B2545   основной текст (тёмно-синий, не чёрный)
kawaii     #FFC9E8   розовый акцент в фоновом узоре (звёздочки/сердечки)
```
Эти цвета просто вписаны как hex прямо в `style=""` — никаких переменных
нет, это обычный плоский HTML (в отличие от прошлой версии в Claude,
где это были `{{sky1}}` и т.п. плейсхолдеры движка Design Canvas —
тут их уже нет, можно просто менять hex-значения напрямую через
find-and-replace, если нужно поменять цвет везде).

## Структура страницы
- Строка пути и языковое меню вверху.
- Навигационный dock открывает внутренние страницы в той же вкладке через
  маршруты `#page=about`, `#page=projects`, `#page=github`, `#page=contact`;
  кнопки не скроллят к якорям и не открывают модальные окна. Browser Back/
  Forward переключает страницы.
- Анимированное локализуемое приветствие.
- Окна `#about` и `#projects`.
- Счётчик уникальных посетителей за всё время внизу (окошко
  "посетители.exe"); его API и JSONL-журналы находятся в `counter.php` и
  вне web-root соответственно.

## Как смотреть изменения
Вёрстку можно открыть напрямую через `index.html`. Счётчик требует HTTP(S)
и настроенный `counter.php`; при открытии через `file://` отображается
многоточие вместо числа. Для проверки счётчика используй PHP-FPM deployment
из раздела ниже.

## Как просить правки (примеры хороших запросов)
- "В блоке #projects у проекта 02 добавь ссылку на GitHub, как у
  проекта 01" — называй конкретный id/блок и что скопировать
- "Сделай кнопку 'резюме.pdf' активной (добавь href на реальный файл
  резюме), сейчас там href='#'"
- "Акцентный синий #4FA8E8 замени на #3FA0E0 везде по файлу"
  (можно просто перечислить старый/новый hex)
- "Добавь четвёртое окно '#contact' в том же стиле, что #about,
  с полями ..."
- "На мобильных (ширина <480px) кнопки в hero съезжают — сделай так,
  чтобы они оставались по центру и не вылезали за край"

Плохо: "сделай сайт лучше" — слишком общо, непонятно что менять.

## Деплой на VPS (keril.art)
На сервере, где уже поднят 3x-ui/VPN-стек (см. vpn-guide.md), сайт
обслуживается через nginx, а счётчик — через PHP-FPM.

```bash
scp index.html counter.php vpnuser@ВАШ_IP:/var/www/keril.art/
```

На сервере (один раз):
```bash
sudo apt install php-fpm
ls /run/php/
sudo install -d -o www-data -g www-data -m 0750 /var/lib/keril.art/counter
sudo install -d -o root -g www-data -m 0750 /etc/keril.art
openssl rand -hex 32 | sudo tee /etc/keril.art/counter-secret >/dev/null
sudo chown root:www-data /etc/keril.art/counter-secret
sudo chmod 0640 /etc/keril.art/counter-secret
sudo mkdir -p /var/www/keril.art
sudo nano /etc/nginx/sites-available/keril.art
```
```nginx
server {
    listen 80;
    server_name keril.art www.keril.art;
    root /var/www/keril.art;
    index index.html;

    location ~ \.php$ {
      try_files $uri =404;
      include snippets/fastcgi-php.conf;
      fastcgi_pass unix:/run/php/php8.4-fpm.sock;
    }
}
```
```bash
sudo ln -s /etc/nginx/sites-available/keril.art /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d keril.art -d www.keril.art
```
(Порт 80/443 должны быть открыты в `ufw` и свободны от других сервисов
— проверить, что certbot ещё не занял их под другой домен.)

В nginx-примере замени `php8.4-fpm.sock` на сокет, который показала
команда `ls /run/php/`. После изменения конфигурации проверь её
(`nginx -t`) и перезагрузи nginx. При следующих обновлениях копируй оба
файла:
```bash
scp index.html counter.php vpnuser@ВАШ_IP:/var/www/keril.art/
```

Счётчик на сайте показывает уникальные браузеры за всё время
(`uniqueVisitorsAllTime`). Их список — `all-visitors.jsonl` в
`/var/lib/keril.art/counter/`: по одной строке на браузер (постоянный
HMAC-хэш cookie и дата первого визита); этот файл не удаляется, отсчёт
идёт с момента выкладки этой версии. Дополнительно каждый просмотр
логируется в дневные `visitors-ГГГГ-ММ-ДД.jsonl` (API также отдаёт
`uniqueVisitorsToday`), они автоматически удаляются через 90 дней.
IP-адрес, User-Agent и Referer не сохраняются; используется случайная
HttpOnly/Secure cookie, в журналы попадают только её HMAC-хэши.

## Пет-проекты на поддоменах (план, не реализовано)
Каждый пет-проект — свой поддомен (`project1.keril.art` и т.п.),
свой отдельный `index.html`/набор файлов, свой `server {}` блок в
nginx и своя папка в `/var/www/`. Общий стиль (палитра, шрифты,
XP-кнопки) стоит унести в происходящий от этого файла шаблон, когда
появится второй проект — но пока рано абстрагировать, делай каждый
поддомен отдельным файлом.
